## 코드 측 보정 후보(번역 커밋으로는 못 고치는 것, 1차 뒤 별도 처리)

- `base-system/widgets.twee` 거리 이름: `<<print _location.toUpperFirst()>> 가` → `getMapNameKr(...)`로 한글 거리명.
- `base-system/tending.twee` 335: `$_plant.tending.planting_bed` 값(earth/water)이 영어로 찍힘.
- `$NPCList[_n].penisdesc` / `breastsdesc` 를 산문에서 직접 찍는 자리(bodywriting 1005, ejaculation 다수, 이후 전투 파일들): 옛 번역은 `window.KR.getPenisDescKr(...)`로 감쌌으나 번역 커밋에서는 변수 그대로 둠. 해결책 후보: 이 값들을 `kr_dict.js` 화면번역 사전에 넣어 후처리로 치환.
- `base-combat/man-combat.twee` 등 전투 파일: `_args[0]`/`$_hand`(left/right)와 `$_toy` 도구명을 산문에 직접 찍음. 옛 번역은 `<<print … ? "왼손" : "오른손">>`·`window.KR.getToolKr()` 래퍼. 후보: kr_dict 화면번역 사전에 도구명·left/right 추가.
- `base-combat/actionsGeneration.twee` 1272~1283: `_mockItems` 객체 키(ethics/looks/strength/skill/penis/pussy)가 `<<optionsfrom>>` 라벨로 화면에 보임. 옛 번역은 `<<option "도덕" "ethics">>`. 키 구조를 바꿔야 하므로 코드 작업.
- `base-combat/effects.twee`·`beast.twee`: `$NPCList[0].fullDescription`, `$combatTrain.beastTypes[...]`, `<<beasttype>>` 결과가 영어(Black Wolf 등)로 찍힘. 옛 번역은 `getDescriptionKr`/`getBeastTypeKr` 래퍼.
- `overworld-town/special-avery/main.twee`: `$avery_helicopter.destination` 값(orphanage, photo studio 등)이 산문에 영어로 찍힘(6곳).
- `<<run Furniture.set('owlplushie', {name:'owl plushie', nameCap:'Owl plushie'})>>`(loc-home/main, special-robin, special-kylar): 가구 이름이 매크로 안 코드 문자열. 화면에 찍히면 kr_dict 또는 코드 변경.
- `$loveInterest.primary` 등 NPC 이름 변수를 산문에 직접 찍는 자리(loc-flats/main 238 등): 옛 번역은 `window.KR.gatPersonNameDictKR()` 래퍼.
- `<<printTime>>`(time-macros.js)가 '1 hour and 5 minutes'처럼 영어 출력(special-avery/mansion housework 등).
- `loc-cafe/main.twee` 2529: `$phase`(음식 이름)가 영어로 찍힘; 옛 번역은 `<<phaseFoodKR>>`.
- 변수 값이 산문에 직접 찍히는 자리: `$changingRoomGender`(boys/girls, loc-school/changing-rooms*), `$farm.steed` 털색(loc-brothel/main 1572), special-avery/cards 298 술 이름·인물 이름. 옛 번역은 if/switch/위젯으로 한글화.
- `loc-forestshop/gwylan-requests.twee` gwylanRequestText: `$_firstWord`/`$_secondWord`의 영어 관사("a set of", "a"/"an")와 `<<= $_shopPrimary>>` 가게 키(clothing/adult/antique/bait)가 영어로 출력. 옛 번역은 `_translateShop`·`setup.colourName`으로 코드 수정.
- `loc-mines/widgets.twee` 166: `$mine.heldGem`(small gem 등) 보석 이름이 영어로 출력.
- **기존 버그** `loc-underground/main.twee` 151–155, `loc-underground/robin.twee` 23–27: 옛 번역이 `robinTopics` 값을 "논의되지 않음"으로 바꿔 놓았는데 코드(robin 21, main 237)는 "undiscussed"와 비교 → 로빈 대화 주제 재충전 조건이 깨졌을 수 있음. 값을 "undiscussed"로 되돌려야 함.
- `loc-mines/main.twee` 168·230: `$phase`(lantern), `_antique`(shovel handle 등) 값이 영어로 출력.
- `special-masturbation/widgets.twee` 99: `$_liquids.formatList({useOxfordComma:true})`의 접속사 'and'가 영어로 출력. 옛 번역은 `formatList($_liquids, "그리고", true)`.
- `special-fishing/moor/fox.twee`, `fishing-text.twee`: `$fishingHookedFish.type`·`_fishingSeasonFish` 물고기 키가 영어로 출력. 옛 번역은 `setup.foodstuff[...].name`.
- `base-system/caption.twee` 294: `<<button CHEATS>>`(따옴표 없는 인자). 옛 번역은 `<<button "치트">>`.
- `loc-museum/painting-ward.twee`: `<<run _antiqueMuseum.push("the " + …)>>`의 관사가 화면에 'the 은 반지'처럼 출력.
- 의상 JS 새 `pattern_name` 값(decorations/charms/weapons/prints/flowers/position/detail 등)이 상점 화면에 영어로 표시. kr_dict 항목 추가 또는 코드.
- `base-system/effect.js` 508: 최면 특성 이름 `trait.toUpperFirst()` 영어 그대로(옛 번역과 동일).
