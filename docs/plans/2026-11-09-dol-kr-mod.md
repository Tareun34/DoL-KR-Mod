# DoL-KR-Mod 저장소 통합 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 한국어 번역 소스 포크 하나(`DoL-KR-Mod`)에서 `./build.sh` 한 번으로 원본 / 원격 저장 / Herm / 둘 다, 네 가지 HTML을 만들고, 세이브 서버를 같은 저장소에서 운영한다.

**Architecture:** Herm 규칙 15개를 twee/JS 소스에 직접 반영하고 설정 UI만 `setup.features?.herm`로 가린다(`features/herm-ui/`를 tweego 소스 인자에 넣고 뺌). 원격 저장은 번들 SugarCube `format.js`의 `idb` 모듈을 교체한 두 번째 스토리 포맷 `sugarcube-2-remote`로 만들고(`tools/make-remote-format.py`가 생성, 생성물 커밋), tweego `-f`로 고른다. 서버는 `dist/`와 `img/`만 허용 목록으로 정적 서빙한다.

**Tech Stack:** bash, Python 3 표준 라이브러리(`unittest`), tweego(저장소 번들 `devTools/tweego/tweego_linux64`), Node 24 + `node --test`(서버), Docker Compose.

**Spec:** `docs/specs/2026-11-09-dol-kr-mod-design.md`

## Global Constraints

- 원본 빌드는 Herm 비율 0에서 모드 없는 번역판과 동일하게 동작하고, 설정 화면에 Herm 항목이 보이지 않는다.
- 기존 세이브(`server/saves/*.json`, `details.json`) 유실 금지. 옛 컨테이너를 내리기 직전에 사용자 확인을 받는다.
- 네 빌드 모두 수동 단계 없이 `./build.sh` 한 번으로 생성된다.
- 저장소에 빌드 HTML(58MB)을 커밋하지 않는다(`dist/`, 루트 `*.html` git-ignore). 기준(baseline) HTML은 저장소 밖 `/home/chan/game/baseline/`에 둔다.
- Python은 표준 라이브러리만. 세이브 API(`/api/*`)는 변경하지 않는다.
- 옛 `herm.py`/`patch.py`는 기준 파일 생성에만 쓰고 저장소에 넣지 않는다. `dol-remote-save`, `DOL_0.5.12.13` 폴더는 삭제하지 않는다(사용자가 정리).
- 커밋 메시지 꼬리말: `Co-Authored-By: Claude Fable 5.1 <noreply@anthropic.com>`.
